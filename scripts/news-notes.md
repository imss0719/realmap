# 월간 리얼맵 — 발행 메모 (다음 호 만들 때 먼저 읽기)

## 고정 구성 (11/3 선배 확정 · 순서 바꾸지 않음, 내용만 매달 교체)
1면 기획 → 부동산 뉴스 3줄 + 이달의 입주 → 이달의 동네 특집 → 리얼맵 새 소식 → 지역별 1위·거래 활발·재개발 단계 변화 → 분양권 시세 + 중개사 상식 Q&A → 다음 호 퀴즈

## 원칙
- 뉴스: 정부·한국은행·서울시 원문 확인 후 리얼맵 문장으로 요약, 원문 링크 필수. 국회 통과 전이면 '정부안' 표시. 전망·예측 쓰지 않음.
- 숫자: 국토부 실거래(price-XX.json) 동네 평균, 거래 10건 이상만 순위. 평당가 = 값 × 3.305785 (전용 기준).
- 사진: 선배 현장 사진 / 리얼맵 지도·그래프 / 공공누리 표시 사진만. 뉴스 사진 금지.
- 예시 상호는 ○○○. 링크는 모두 ?from=news.
- 발행 파일: 루트 news.html (최신 호). 다음 호 낼 때 지난 호는 news-2026-11.html 처럼 이름 바꿔 보관.
