# 리얼맵 설치 안내

지도에서 필지를 누르면 로드뷰, 토지특성, 소유정보, 토지이용계획, 공시지가, 건축물대장(표제부·층별), 동·호별 면적과 공동주택가격, 실거래가(매매·전월세)를 한 화면에 보여 주는 사이트입니다.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.css`, `app.js` | 화면 (카카오 지도, 로드뷰, 정보 패널) |
| `check.html` | 연결 점검 페이지 |
| `api/parcel.js` | 클릭한 위치의 필지 경계·PNU (브이월드 연속지적도) |
| `api/land.js` | 토지특성·토지이용계획·소유정보·개별공시지가 (브이월드) |
| `api/building.js` | 건축물대장 총괄표제부·표제부·층별개요 (건축HUB) |
| `api/units.js` | 동·호 목록, 호별 전유·공용면적, 공동주택가격 |
| `api/trades.js` | 국토교통부 실거래가 (매매·전월세) |
| `api/health.js` | 키 연결 점검 |

## 1단계. 공공데이터포털 활용신청

data.go.kr 에서 아래 API를 검색해 각각 [활용신청]합니다. 개발계정은 자동 승인되며, 실제로 작동하기까지 1~2시간 걸릴 수 있습니다.

- 국토교통부_건축HUB_건축물대장정보 서비스
- 국토교통부_아파트 매매 실거래가 상세 자료
- 국토교통부_아파트 전월세 실거래가 자료
- 국토교통부_연립다세대 매매 실거래가 자료
- 국토교통부_연립다세대 전월세 실거래가 자료
- 국토교통부_단독/다가구 매매 실거래가 자료
- 국토교통부_단독/다가구 전월세 실거래가 자료
- 국토교통부_오피스텔 매매 실거래가 자료
- 국토교통부_오피스텔 전월세 실거래가 자료
- 국토교통부_상업업무용 부동산 매매 실거래가 자료
- 국토교통부_토지 매매 실거래가 자료

마이페이지의 **일반 인증키(Decoding)** 를 복사해 둡니다.

## 2단계. GitHub · Vercel 가입

1. github.com 가입
2. vercel.com 에서 [Sign Up] → [Continue with GitHub]

## 3단계. 사이트 올리기

1. GitHub 오른쪽 위 [+] → [New repository] → 이름 `realmap`, Private 선택 → [Create repository]
2. 새 저장소 화면에서 [uploading an existing file] 클릭
3. 압축을 푼 폴더 **안의 파일과 api 폴더 전체**를 끌어다 놓고 [Commit changes]
   - 저장소 첫 화면에 `index.html` 과 `api` 폴더가 바로 보여야 합니다.
4. Vercel 대시보드 → [Add New…] → [Project] → `realmap` 옆 [Import] → 설정은 그대로 두고 [Deploy]
5. 완료되면 `https://realmap-xxxx.vercel.app` 같은 주소가 생깁니다. 이 주소를 메모해 둡니다.

## 4단계. 카카오 키 (지도·로드뷰·주소검색)

1. developers.kakao.com 로그인 → [내 애플리케이션] → [애플리케이션 추가하기]
2. 만든 앱 → [앱 키]에서 **JavaScript 키** 복사
3. [앱 설정 › 플랫폼 › Web 플랫폼 등록] → 사이트 도메인에 3단계 주소 입력 (`https://` 포함)
4. 카카오맵 사용 설정 메뉴가 보이면 [사용]으로 바꿉니다.

## 5단계. 브이월드 키 (지적도·토지 정보)

1. vworld.kr 회원가입 → [오픈API] → [인증키 발급]
2. 서비스 URL에 3단계 주소 입력, 활용 API는 모두 선택
3. 발급된 인증키 복사

## 6단계. 키 등록 후 다시 배포

Vercel → 프로젝트 → [Settings] → [Environment Variables]에서 아래 3개를 추가합니다.

| 이름 (Key) | 값 (Value) |
|---|---|
| `KAKAO_JS_KEY` | 카카오 JavaScript 키 |
| `VWORLD_KEY` | 브이월드 인증키 |
| `DATA_GO_KR_KEY` | 공공데이터포털 일반 인증키 (Decoding) |

선택 항목
- `SITE_NAME`: 서비스 이름을 넣으면 화면 제목이 바뀝니다.
- `VWORLD_DOMAIN`: 나중에 개인 도메인을 연결하면 브이월드에 등록한 주소를 넣습니다. 비워 두면 Vercel 주소를 자동으로 씁니다.

[Deployments] → 맨 위 배포 오른쪽 [⋯] → [Redeploy]를 누르면 반영됩니다.

## 7단계. 점검

`https://내주소/check.html` 을 열면 키마다 실제로 호출한 결과가 나옵니다. 모두 '정상'이면 지도에서 필지를 눌러 확인합니다. '확인 필요'가 있으면 화면을 캡처해 주세요.

## 알아 두실 점

- **호출 한도**: 공공데이터포털 개발계정은 API마다 하루 호출 횟수 제한이 있습니다. 실거래 탭은 월별로 자료를 모으므로 기간을 길게 잡을수록 호출이 많아집니다. 서비스를 공개하기 전에 각 API를 운영계정으로 전환 신청해 주세요.
- **지번이 가려진 거래**: 단독·다가구, 상업업무용, 토지 실거래는 국토교통부가 지번 일부를 가려서 공개합니다. 같은 동에서 면적이 일치하는 거래를 '추정'으로 표시합니다.
- **소유자 성명**: 공개 데이터에는 없습니다. 소유구분·공유인수·변동원인·변동일자까지만 제공됩니다.
- **Vercel 요금제**: 무료(Hobby) 요금제는 비상업용입니다. 정식 서비스로 운영할 때는 Pro 요금제 전환을 검토해 주세요.
- **공공누리**: 화면 하단의 출처 표기는 그대로 유지해 주세요.

## 개발지도

- 지도 오른쪽 **[개발지도]** 버튼으로 켭니다.
- **정비구역(재개발·재건축)**: `data/jeongbi-seoul.json` 파일을 씁니다. 원본은 브이월드에서 내려받은 국토부 「(연속주제) 도시및주거환경정비/정비구역」 서울 파일(LSMD_CONT_UD602_11)입니다. 한 달에 한 번 정도 새 파일을 받아 Claude에게 주면 변환해서 이 파일만 바꿔 올리면 됩니다.
- **공공 도시계획 레이어**(지구단위계획, 토지거래허가구역 등): 브이월드 키로 자동 표시됩니다.
- **리얼워커스 개발정보(직접 등록)**: 선택 기능입니다. 쓰려면 Vercel Storage에서 Upstash Redis를 연결하고 `ADMIN_PASSWORD`를 넣은 뒤 `/admin.html`에서 등록합니다.
